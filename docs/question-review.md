## 내부 검수

원고를 읽고 정답의 타당성, 각 오답과의 구별, 질문의 조건, 해설 문장의 일관성을 AI가 내부 검토했다. 정답 번호는 1~4 순환으로 배치했다. 질문은 기본 개념을 제한적으로 다루며 전문 시험의 난이도나 전체 출제기준을 포괄하지 않는다. 정답이 과도하게 쉽게 드러나는 오답과 절차 확인형 문항이 포함되어 있어 실전 난이도 검증은 별도 필요하다.
