## 단원과 학습 과제

각 과목에서 10개 묶음, 각 묶음에서 6개 개념을 작성했다. 개념마다 다음 세 과제를 구분했다.

1. 정의를 읽고 비슷한 용어 중 해당 개념을 선택하는 개념 확인.
2. 행동·상황 사례를 분석해 적용 개념을 판단하는 사례 적용.
3. 잘못된 명제를 읽고 오류를 바로잡는 설명을 선택하는 오개념 판별.

문장 어미나 숫자만 바꾼 변형을 만들지 않았다. 같은 개념을 재학습하는 연결성은 의도된 것이므로 독립 개념 수로 집계하지 않는다. 정의 문제와 사례 문제는 같은 용어를 정답으로 가질 수 있지만, 단순 정의 회상과 상황 분석의 학습 과제를 구분한다.

## 검수 범위와 한계

AI가 원고의 개념 정의·사례 대응·잘못된 명제와 수정문을 내부 검토했다. 법규 문항은 개정 민감 수치나 개별 사건의 확정 법률 결론을 생성하지 않고 기본 개념과 검토 절차를 다룬다. 임금·근로시간 등의 법적 요건 전체를 제공하는 자료는 아니다.

자동 검사는 ID 고유성, NFKC·공백 정규화한 본문, 정렬한 보기까지 포함한 지문 중복, 보기4개·보기 고유성, 정답번호 범위, 해설·출처·권리·연도 필드, 과목별200개, 정답위치별250개, 연결개념별3형식, 실전 family 중복 방지 및 기존100개 불변성을 확인한다. 구조 검사는 정답의 학문적·법적 정확성을 입증하지 않는다.

의미상 중복은 원고에서 정의·사례·오류 수정의 과제가 구별되는지 내부 검토한 범위다. 모든 의미 중복이 독립적으로 제거되었다고 보장하지 않는다. 기초적인 사례와 쉽게 배제 가능한 오답도 포함되므로 실제 시험의 난이도와 출제 비중을 재현한다고 주장하지 않는다.
