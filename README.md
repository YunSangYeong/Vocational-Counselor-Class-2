# 직업상담사2급 필기 CBT

React + TypeScript + Vite 기반 비공식 학습 앱. 전기기능사 CBT의 지정 코드와 화면을 재사용한다. 최신 표준 v1.4.0의 스킬 폴더 전체와 연결 지침은 [AGENTS.md](AGENTS.md)에 있다.

**현재 구현·로컬 검증은 완료했지만, 1,000문항 수량 기준과 최신 공식 시험 규칙 대조는 미완료이며 배포 사전 API 확인에서 중단했다.**

## 기능

- 실전 모의시험과 랜덤 문제풀이, 학습 기준·버전 선택 메뉴 없음.
- 실전 답안 선택 후, 랜덤 즉시 채점 후 Space로 다음 문제. 미응답·길게 누르기·IME·수정키·입력 컨트롤·열린 메뉴·확인창 보호. 마지막 시험 문제에서 자동 제출 없음.
- 한 문제씩 표시, 번호 이동·답안 수정·북마크, 시험 중 정답 비공개, 제출 후 전체 보기·해설·오답 필터·재학습.
- 절대 종료 시각 기반 150분 타이머, 새로고침 복원, 만료 자동 제출·중복 제출 방지.
- 오답노트·북마크·과목별 통계·학습 이어하기. 랜덤 순회 내 ID 중복 방지, 재학습 정답 시 오답 해제.
- JSON/CSV 등록·중복 제거·검증 대기·근거 입력 후 로컬 승인·검색·상태 필터·페이지·내보내기.
- 모바일 고정 메뉴 독립 세로 스크롤, 작은 높이·가로 모드·확대 글자 대응. 실제 휠·터치 회귀 검사 포함.
- 상단 상시 면책 배너 없음. 비공식 표시는 사이드바·푸터, 근거와 한계는 문제은행 관리 및 이 문서에 표시. 실제 저장 실패·손상 경고는 유지.

## 시험 규칙의 확인 상태

설정은 `src/qualification-profile.json`으로 분리했다. `rulesVerificationStatus: pending`이다.

| 항목 | 학습용 잠정 설정 (공식 원문 직접 확인 미완료) |
|---|---|
| 자격증 | 직업상담사2급 필기 |
| 과목 | 직업심리 / 직업상담 및 취업지원 / 직업정보 / 노동시장 / 고용노동관계법규 |
| 문항 | 과목별20, 총100, 객관식4지선다 |
| 시간 | 150분 |
| 채점 | 과목당100점(문항당5점), 전체는 과목 평균. 미응답 오답 |
| 합격 | 평균60점 이상이며 모든 과목40점 이상. 표시 반올림 전 비율로 판정 |

공식 확인 대상: [Q-Net 종목 정보](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9511). 실제 요청은 `CONNECT tunnel failed, response 403`으로 본문 확인 실패. 위 값과 과목명을 최신 공식 규칙으로 검증 완료했다고 주장하지 않는다. 최신 출제기준·시험 공고를 대조해야 한다. 실기 시험은 구현하지 않았다.

현재 기본 은행은 과목별20개뿐이라 실전 모드는 동일한100문항의 순서만 무작위화한다. 확장 시 family당 우선1개 선택 후 부족분은 ID 중복 없이 보충한다.

## 실제 문제은행과 이용 조건

| 과목 | 자체 제작·내부 검수 |
|---|---:|
| 직업심리 | 20 |
| 직업상담 및 취업지원 | 20 |
| 직업정보 | 20 |
| 노동시장 | 20 |
| 고용노동관계법규 | 20 |
| 합계 | **100** |

기출0 / 복원0 / 자체 제작100 / 숫자 조건 변형0 / 계산형0 / 검증 대기 기본 등록0. 중복 제거 후 내부 검수100개이며 **목표1,000 대비900개 부족**하다. 개인 로컬 등록은 포함하지 않는다. 1,000문항 표준 충족으로 처리하지 않는다.

AI 일반 지식 기반 원고를 내부 검토한 입문 개념형이며, 외부 전문가 검수와 공식 출제기준 대조는 미완료다. 기출의 출처·연도·회차·재배포 허락을 만들지 않았다. 법규는 기본 개념과 확인 절차 중심이고 최신 법정 수치·제도 전체를 다루지 않는다. 문제의 전문 난이도·출제범위 대표성은 검증하지 않았다. [출처·검수 범위](docs/question-review.md) 참조.

## 개발과 검증

Node24.19.0 (`.node-version`), npm11.9.0. 별도 서버·로그인·API 키 없음. 기존 checkout을 사용하며 별도 worktree를 만들 필요가 없다.

```sh
cd /workspace/Vocational-Counselor-Class-2
npm ci --cache /tmp/cbt-npm-cache
npm run dev -- --port 5173 --strictPort
```

```sh
npm test
npm run build
# 이 클라우드에는 시스템 Chromium이 설치되어 있다.
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# 일반 환경에서는 npx playwright install --with-deps chromium 후 npm run test:e2e
python scripts/generate-bank.py
```

단위116개, PC·모바일 브라우저30개 통과. 타입 검사와 프로덕션 빌드 통과. PC·Pixel7 Chromium 에뮬레이션이며 실제 모바일 기기 검증은 아니다. 실행 명령·최초 로컬 실패 진단·검증 범위는 [검증 기록](docs/validation.md)에 있다.

기록은 `vocational-counselor-2:v1` localStorage에 저장한다. 최근 응답5,000개와 시험30회 한도이며 통계도 그 범위다. 진행 중 시험·랜덤 세션·오답·북마크·로컬 문항을 저장한다. 손상된 원본을 자동 덮어쓰지 않고 저장 실패를 경고한다. 백업은 JSON 내보내기이며 학습 기록 복원 UI는 제공하지 않는다. 초기화는 확인 후 로컬 기록·가져온 문항을 삭제하며 기본100문항은 유지한다. 다른 브라우저·기기·origin 간 동기화는 없다. 같은 GitHub Pages 소유자의 다른 앱과 저장 키를 구분한다.

## GitHub와 Pages 상태

workflow는 **main push → validate(단위·빌드·PC/모바일) 성공 → Pages 배포**, PR은 validate만 실행하도록 준비했다. 배포 job만 pages/id-token 쓰기 권한을 가진다. 같은 커밋의 자동 실행에 수동 실행을 추가하지 않는다.

배포 사전 확인의 첫 요청이 다음 오류로 차단됐다.

```text
Get "https://api.github.com/repos/YunSangYeong/Vocational-Counselor-Class-2": Forbidden
```

사용자의 지시에 따라 재시도·대체 배포·main 푸시 없이 중단했다. 코드 보존 브랜치는 `feat/vocational-counselor-cbt`이며 Pages push 트리거 대상이 아니다. CI 실행·Pages 배포는 시작하지 않았고, 기존 Pages 설정·게시 상태·공개 화면은 미확인이다. 다른 프로젝트는 수정하거나 재배포하지 않았다.

사용자의 다음 최소 동작 하나: **클라우드 환경 인터넷 허용 도메인에 `api.github.com` 추가**. 이번 작업에서 자동 재시도하지 않는다. 이것만으로 API 인증·Pages 권한이 보장되지는 않는다. 이후 배포 마무리는 사용자가 진행한다.

예상 기본 URL: https://YunSangYeong.github.io/Vocational-Counselor-Class-2/ (배포 성공 또는 공개 접속 확인을 뜻하지 않음).
